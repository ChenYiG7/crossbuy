## 二、常设纪律（贯穿 R1，每域每周期适用）

### 2.1 域绞杀 DoD
每域切写门槛 checklist 见 **docs/04 §5.6**（三入口就绪 / PHPUnit 等价 / 演练 diff=0 / 安全复核 / 灰度回退预案 / 旧模块下线 / ≥2 周窗口）。任何一项不满足即中止，按回退预案退回。

### 2.2 CI 门禁（M0 落地，此后不可降级）

- `pnpm typecheck && pnpm build` 必绿；
- ESLint **边界规则**：`PrismaClient` 仅 `domains/*/repository`、域间禁 import、`contract` 禁 ORM/框架类型——M0 用**故意违规样例**验证 CI 真会拦；
- 敏感接口鉴权用例（docs/04 §10：管理/资金类接口未授权必失败）为必过项，防旧后门以「兼容」名义复活；
- 演练/对账结果统计用精确计数（`awk -F'\t'` 结果列），**禁 `grep -c FAIL`**；任何「0/空/无差异」必须第二独立来源交叉核对（MEMORY 血泪坑 2：校验脚本自己会造假绿）。

### 2.3 R2 触发器与资产保鲜（本方案成立的两个前提之一）

- **M5 验收 = R2 启动点**，两者之间不插新功能迭代（docs/04 §9）；
- `prisma/redesign/schema.prisma` 纳入日常 `db:generate` + `typecheck`（保鲜，防封存腐烂）；
- 复现怪癖逐条登记 `docs/plans/08-R2优化清单.md`，PR 发现未登记的怪癖复现 = 打回。

### 2.4 契约变更登记制（外包 PHP 维持期）

任何改变接口行为/字段语义/金额口径的 PHP 侧改动，必须提前告知并重录契约基线；纯 bugfix 不受限。基线漂移 = 演练 diff 全部作废。

## 四、M1 member 垂直切片（试水 + 熔断点）

> 目的不是「做出会员」，是**跑通整套新链路**并验证本方案成立。member 旧系统文档最全（19 篇）、边界最清。

1. **契约校准**：已有 `contract/domains/member` 按旧表语义核对（登录 collation 等价、字段映射、dfFlag 分流）。
2. **repository 防腐层**：member 侧 15 表（TODO #3e 清单）读路径先行——时间戳 Asia/Shanghai、username 旧 collation 语义、`money` 读入 Decimal。
3. **service**：只读起步（`GET /api/customer/v1/member/me`，风险最低）→ 写路径（资料编辑、**MD5 登录透明升级 argon2id**、收藏增删）；事务边界在 service；余额类读写走 finance 域接口（表属主）。
4. **页面**：web 会员页 + admin「用户管理」模块（新老并行，员工可培训）。
5. **测试**：member 域 PHPUnit 用例全量翻译 Vitest + service 单测 TDD。
6. **写路径演练**：测试库副本上同输入跑 PHP 与 TS，副作用逐行 diff（资料变更/密码升级/收藏）。
7. **灰度**：nginx 按 URL 切会员页流量，跑满 ≥2 周业务周期窗口。

**熔断判据**：member 域无法做到「演练零差异 + 灰度零告警」→ 项目叫停，损失封顶 ≈2 个月；复盘后再决定是否回退旧路线（60 模型资产仍在，可退回 docs/plans/03 的 T0/T1 路线）。

## 五、M2~M5 概要

- **M2 交易链路**：先补知识再动刀（#2：bargainprice 双语义、goodsprice 族、状态机文档化）→ order → purchase → send-order；web/mzk 核心购买页随域灰度；五费/砍价总额演练对账（复用 `0013`/`0018` 已验证的口径断言思路做运行时对账脚本）。
- **M3 履约链**：MNS Node SDK spike **前置**（不行则走 MNS HTTP API 自签，工作量另评）；logistics → platform → worker 分批接管 56~58 个 Job（每个幂等键 + 唯一键 upsert）；webhook 全量迁 apps/api（Rakuten 强制签名 = 安全项必修）。
- **M4 收尾**：admin 全量模块（老 dcat-admin 按模块灰度下线）；ticket/content P3 域「能留则留、JIT 盘点死功能剪枝」；finance **纯平移**（#11a 逐条对策过审是硬门槛；F7~F9 安全项随域即修）。
- **M5 退役**：GraphQL / Job / 壳页 / 旧 admin 全下线；`haiou` 只读归档；**R2 启动**。

## 六、红线（R1 版，违反即停工）

1. **禁 Big Bang**：新旧并行，旧系统随时可回退；
2. **共用旧表**：R1 零新表（唯一例外 = admin 权限自用表族）；**PHP 唯一写方直到该域绞杀**，禁两系统同写一域；
3. **金额不可信**：服务端重算 + `utils/money` Decimal 单入口 + 余额唯一写入口（写旧表也一样）；
4. **幂等**：webhook/队列/拉单一律唯一键 upsert；
5. **旧系统只读**：haiou 不改不提交；生产旧库只在域绞杀流程内写；
6. **复现纪律**：业务行为 1:1（含怪癖），怪癖必登记 `docs/plans/08`；安全 P0/P1 例外必修；
7. **R2 触发器**：M5 即 R2，之间不插新功能迭代。
