# 07 表属主映射（生产 180 对象 → 域）

> 状态：M0 交付物**骨架**（2026-10-16 建）；底稿 = `docs/plans/00`（表清单盘点）；规则见 `docs/04` §3.2。
> 用途：① 跨域读必须走属主域 service 的裁决依据；② R3 拆分时「表随域走」的清单；③ R2 回填脚本的对账底稿。

## 一、规则

1. **每张表唯一属主域**；跨域读 = 调属主域 service 接口，禁直连表（ESLint 边界规则强制，见 docs/06 §2.2）。
2. 字典/关联表跟着「**谁写谁拥有**」走。
3. 旧系统多态列（`oid`/`tid` 等跨域引用）一律在**属主域的 repository** 内收口转换，不许在别域裸 JOIN。
4. 被多域读写的争议表标 ⚠，M0 逐张裁决并记录理由，不许留「共享表」。

**★ tinyint(1) → Boolean 陷阱（2026-10-17 实测，P0 数据保真）**：MySQL 的 `TINYINT(1)` 只是
「显示宽度 1」，**实际能存 -128..127**；而 Prisma 一律把 tinyint(1) introspect 成 `Boolean`
⇒ 非 0/1 值在读写时被**静默塌成 true/false**。生产/本机实测在招的列：

| 列                   | 实际取值                                | 影响                                                                |
| -------------------- | --------------------------------------- | ------------------------------------------------------------------- |
| `dg_users.usetype`   | 0..5（**643 / 5,021 会员是非 0/1 值**） | 会员「帐号用途」枚举（代理購入/転送/無在庫/OEM/1688转运）被吞掉区分 |
| `dg_record.ordflag`  | 0..3                                    | **807 万行余额流水**                                                |
| `dg_sendorder.otype` | 1..3                                    | 运单类型                                                            |
| `dg_favorite.type`   | 1..3                                    | 收藏类型                                                            |

**处置**：`packages/db/scripts/post-pull-fixup.mjs` 把所有 `Boolean` 一律降级为 `Int @db.TinyInt`
（保真优先；introspect 阶段无法区分「真布尔」与「用 tinyint 装的枚举」，而失真不可接受）。
纯静态改写、幂等、不连数据库 ⇒ 每次 pull 后自动生效。需要布尔语义的列在 contract / 域层自行转换。
修复后运行时已验证可读出 `usetype` 的 2/3/4/5 真值（修复前只能得到 true）。

**生产重拉顺带解开的旧疑（#11e⑥ / Q13）**：`v2_worldfirst_*` 五张表（trade_order / collection_statement / statement_recharge / notify / attachment）**在生产真实存在，但全部 0 行**——「旧系统唯一真对账实现」实际是空壳死表；`v2_member_webhook` 同样 0 行（注册未用）。⇒ finance 域对账能力**没有历史包袱可继承**，R2/R3 账本对账从零建（docs/plans/08-F 族的前提不变）。

**首拉（本机 dump 160 表版）已废止**：该版曾造成 14 表缺失 + `dg_users` 74/75 列漂移，仅存活于 git 历史（commit `6d95be1`）；其 3 个 `0908_*` 撞名修复场景在生产不复现，`post-pull-fixup.mjs` 的撞名逻辑保留防将来其他来源的 pull。
