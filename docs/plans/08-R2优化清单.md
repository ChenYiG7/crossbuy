## 二、结构类

| # | 问题 | R1 处置 | R2/R3 处置 |
|---|------|---------|-----------|
| S1 | `username` collation `utf8_general_ci`（尾空格/大小写折叠、全半角假名不折叠） | 登录查找按旧 collation 语义**等价复现** | `utf8mb4_general_ci` + `docs/plans/02` 消歧方案 |
| S2 | MD5 无盐密码 | 校验 MD5 + 登录透明升级 argon2id | 清除残余 MD5（低活跃账号强制重置） |
| S3 | INT unix 时间戳 | repository 统一转 DateTime（**Asia/Shanghai**） | DateTime 列 |
| S4 | `email` 不唯一（`123456@qq.com` ×31 测试号） | 复现不加唯一 | 清测试号后加唯一 |
| S5 | `bargainprice` 在 Order/SendOrder 语义不同；`goodsprice` vs `goodsprice1` | 防腐层显式命名 + 注释，禁照搬 | 拆字段/值对象（60 模型已定） |
| S6 | 多态外键（oid/tid 跨域引用） | 属主域 repository 收口 | 显式外键 |
| S7 | `dg_order.idx_sid` 类型不匹配致索引失效（150 sid 查 4.5 分钟） | 一律 oid 主键 `IN` 路径 | 改类型或删索引 |
| S8 | `admin_operation_log` 亿级直写 | 新后台异步 + 分区归档 | 归档策略固化 |
| S9 | `float_rate` / `order_weight` / `low_multiple` 非金额列易被口径清扫误伤 | 防腐层显式类型（非 Money） | 60 模型已正名 |

## 三、登记纪律

1. R1 期间每发现一个「照抄了但知道是错/怪」的点 → 在对应分区加一行：现象 + 实测证据（行数/样例/旧代码位置）+ R1 处置。
2. 提交信息引用本文件；PR 审查发现未登记的复现怪癖 = 打回。
3. R2 立项时本文冻结为需求基线，逐条排期；R1 期间**不提前修**任何资金类复现项（安全项 F7~F9 除外）。
