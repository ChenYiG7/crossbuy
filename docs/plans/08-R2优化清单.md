# 08 R2 优化清单（R1 复现期的怪癖与缺陷登记簿）

> 状态：活文档，R1 期间**持续追加**；R2 立项时**冻结为需求基线**（docs/04 §12.1 启动门槛）。
> 规则：R1 对业务行为 1:1 复现，**明知是错的也要照抄**（复现红线，docs/04 §1）——但每照抄一次必须在此登记一行。**没登记 = R2 永远不知道这里要修。** 唯一例外是安全项（标记为「R1 即修」，不在 R1 复现）。

## 三、登记纪律

1. R1 期间每发现一个「照抄了但知道是错/怪」的点 → 在对应分区加一行：现象 + 实测证据（行数/样例/旧代码位置）+ R1 处置。
2. 提交信息引用本文件；PR 审查发现未登记的复现怪癖 = 打回。
3. R2 立项时本文冻结为需求基线，逐条排期；R1 期间**不提前修**任何资金类复现项（安全项 F7~F9 除外）。
