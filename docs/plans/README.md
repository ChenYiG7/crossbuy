# 实施计划书（docs/plans）

> 一个域/一个任务一份计划书，实施完归档到 `archive/`。README 做状态索引。

## 模板（八节）

复制 `_template.md`，填下面八节：

1. **元信息**：日期 / 涉及域 / TODO 编号
2. **背景**：为什么做、上游依据（docs/03、docs/06）
3. **方案**：技术方案 2-3 句 + 关键取舍
4. **步骤**：bite-sized 任务清单（每步 2-5 分钟粒度），用 `- [ ]` 追踪
5. **表草案**：涉及的表/字段/唯一键
6. **验收**：可验证的出口标准（命令 + 预期输出）
7. **红线**：本项目红线（金额/幂等/只读旧系统）+ 本条特有风险
8. **交接**：未尽事项 + 下一步

> 同一目录下的 `execution-prompts.md` 存档可投喂 AI 的执行提示词（复用第二遍省掉整个摸索过程）。
